File categories

Each category is a list of glob patterns, one per line. Toggle categories from the Hide files menu on commit and PR diff pages.

Pattern syntax
*
any characters except /
**
any characters including /; **/ also matches no directories
? [a-z] [!a-z]
one character, a class, a negated class
{a,b}
alternatives, nestable: *.{test,spec}.{js,ts{,x}}
no /
matches a file or directory name at any depth: *.md, __snapshots__
contains /
anchored at the repo root: docs/**; use **/docs/** for any depth
trailing /
directories only: fixtures/
!pattern
exclude; the last matching line wins
